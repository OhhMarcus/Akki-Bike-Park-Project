# Photos (swap these in)

Use AKKI's own photos (with permission). The file name is the slot; any of jpg, jpeg, png, webp or avif works. Restart `npm run dev` (or run `npm run images`) after adding files. Wide action shots work best; the site adds the dark edge fades itself.

| Slot (file name) | Where it shows |
| --- | --- |
| `home-ride` | Full-bleed action band on the home page |
| `pump-track` | Pump Track page header |
| `lessons-foundation` | Foundation Class card |
| `lessons-advanced` | Advanced Class card |
| `lessons-header` | Lessons page header |
| `events-race` | Race events (cards + event page) |
| `events-nightjam` | Night jams |
| `events-groupride` | Group rides |
| `events-kidscamp` | Kids camps |
| `club` | AKKI Bike Club page |
| `visit` | Visit page header |
| `coach-a`, `coach-b`, `coach-c` | Coach portraits (square) |
| `gallery-1` … `gallery-4` | Home page photo strip |

Keep each file under ~500 KB.
